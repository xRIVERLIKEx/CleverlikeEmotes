      How to install in Minecraft Education
      1. Open the downloaded .mcaddon on the computer with Minecraft Education. It imports both packs.
      2. Create or edit a world. Under Behavior Packs, activate My Emotes BP. The resource pack is added with it.
      3. Join the world. Everyone gets the Emote Book the first time they join. With cheats on, /function …/give hands out another.
      4. Updating? Download again here; the version goes up by one so Minecraft replaces the old copy.

      Design the item icon

      Draw on the 16 × 16 grid. Right-click (or the eraser) clears a pixel; checkered squares stay see-through.
